04  ·  Objetivos

Objetivos

🎯 Objetivo General
Crear y validar una aplicación interactiva, modular y robusta para la supervisión analítica de ejercicios físicos a distancia utilizando Inteligencia Artificial.
🧩
Arquitectura Modular
Diseñar un sistema escalable orientado a objetos que permita incorporar fácilmente nuevos ejercicios fisioterapéuticos en el futuro.
📐
Precisión Geométrica
Desarrollar una máquina de estados finita con NumPy para calcular y auditar en tiempo real los rangos articulares correctos del paciente.
📁
Gestión de Historiales
Implementar un sistema de bases de datos relacionales seguro y eficiente para almacenar el historial de los pacientes.
👥
Interfaces Adaptadas
Proporcionar una interfaz gráfica dual optimizada: una para que el fisioterapeuta analice datos y otra sencilla e intuitiva para el paciente.
